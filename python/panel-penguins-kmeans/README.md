# Panel K-Means

Cluster penguins and filter the table from the chart.

Scope: Python app; Panel websocket sessions; Vega brushing; proxy root path.

The app is the [Penguin KMeans Clustering](https://panel.holoviz.org/en/docs/latest/gallery/penguin_kmeans.html) example from the Panel gallery.
`serve.py` starts `panel serve` on the port Ricochet assigns and passes the app's URL prefix as `--root-path`.

See the [app catalog](../../README.md#app-catalog) for deployment instructions.
