# Marimo Tables

Explore selectable and styled tables.

Scope: Reactive notebook; table widgets; Python service.

Deploy with `ricochet deploy python/marimo-high-dim-data` from the repository root.
For a local preview, run `uv run serve.py` from this directory and open <http://localhost:8000>.

See the [app catalog](../../README.md#app-catalog) for deployment instructions.
